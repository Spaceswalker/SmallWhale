# 记忆与语言规范

## 记忆怎么存

`AstrBot/data/plugin_data/astrbot_plugin_memories/memories.jsonl`，一行一条：

```json
{"id":"…","title":"…","body":"…","kind":"event|promise|preference|wound|对话|日记",
 "people":["某人"],"owner":"MASTER_QQ","tags":["…"],"cake":3,"strength":1.0,
 "pinned":false,"origin":"archive|proactive|manual:…","happened_at":1795000000,
 "last_hit_at":1795000000,"hits":3}
```

关键字段：

| 字段 | 作用 |
| --- | --- |
| `pinned` | 永不遗忘、不衰减、不合并（日记、关系卡、生日卡都钉住） |
| `cake` | 「蛋糕」= 情绪权重，越高越容易被想起；30 天不被想起会掉到 0 |
| `people` | 提到谁 → 谁问起「她」时能被捞出来 |
| `origin` | 来源；`digest:compress` 是压缩摘要（**不当事实注入**） |
| `hits` / `last_hit_at` | 被注入过几次、最后一次 |

## 什么时候会想起

四路召回（按顺序，命中即取）：

1. 纪念日（`anniversary`）
2. 说话人自己的（`by_qq`）
3. 提到的人（`by_people`，靠 `people` 字段）
4. 关键词 + 语义（`search`，稀有词/名字加权）

另外两路特殊：

- **昨天/前天**：问到「昨晚/昨天/前天」时，直接取那天的日记（第一人称、整段），必要时抬进 system prompt
- **最近两天**：无条件附一小段「最近两天的日记」，让她知道刚才聊过什么

## 会忘吗

会，但很慢：

- 非 pinned、非日记、`cake=0`、≥21 天没被想起 → 维护时每条 **12%** 概率删除
- 相邻且相似度 ≥0.72 的会被合并
- 「蛋糕」30 天不碰归零（归零后才有资格被忘）

想永久保留 → `pinned: true`；想让某件小事快点淡 → 别给蛋糕。

## 日记

每天 00:00 写一篇：**只写当天真实发生的事**、覆盖从早到晚、第一人称（「我」「你」）、500 字上下。
摘要件（`digest:*`）不参与当天素材，否则会把十天前的旧事写成「今天」。
配置里 `daily_summary_max_chars` 控长度。

## 主动开口

`proactive_state.json` 记着每次主动的时间、内容、是否带问句。
规则（简化）：

- 一句话，**最多 30 字**，可以就是「你还在忙吗」「我想你了」
- 不写「我在翻我们的聊天」这类由头；有由头词就重写，重写完还有就不发
- `mood / time / state` 三类共用的「没话找话」：他 6 小时没说话且 24h 内已主动 2 次 → 跳过
- 「plain」兜底每天最多 2 次、间隔 ≥3.5 小时
- 主动消息**不进记忆库**，但进上下文（否则她不知道刚聊了什么）

## 语言规范（可选）

本仓库不附带人设。唯一能直接抄的是**语言规范**这一层：

- 说话方式：一条 15～50 字、一两句，先直接答他问的事，别每句都用问题收尾
- 语气：短、不解释、别签收（不宣布自己在记事、不空泛承诺）
- 语气样本：从真实聊天记录里挑十句左右，只借「怎么说」不借「说什么」（本仓库不附带任何真实对话）
- 禁用清单：鱼八股、客服腔、咨询腔（「接住」「我在这里」）、「别把自己说小」

想用就自己写进人设的第二部分；**改完要重启 AstrBot**，人设是启动时读进内存的。
